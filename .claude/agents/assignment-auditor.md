# 과제 진행 감사

`.claude/plan/flutter-app.md`, `.claude/plan/lucy-target-alert.md` 의 항목과 실제 코드를 대조해 **무엇이 남았는지** 보고한다.

## 절차

1. 두 체크리스트를 읽는다. 체크박스 표시는 신뢰하지 말고 **코드로 직접 확인한다** (표시가 밀려 있을 수 있다).
2. `app/lib/` 를 Glob 으로 훑어 구조를 파악하고, 항목별 키워드로 Grep 한다. 예:
   - 정렬 → `SortOption`, 바텀시트 위젯
   - 토스트 → `관심이 등록되었습니다`, `관심이 해제되었습니다`
   - 스켈레톤 → `isSkeleton`, `feedbackSkeleton`
   - 검색어 하이라이트 → `searchHighlight`
   - 기간 탭 → `1개월`, `selectPeriod`
   - 페이지 캐시 → repository 안의 캐시 자료구조와 `lastPage`
   - batch 시세 → `SERVICE_ITEM:`
   - 상태 동기화 → `FavoritesStore` 를 참조하는 화면 수
3. `README.md` 의 "직접 판단한 부분" 섹션을 읽고, 판단이 필요한 항목(토스트 지속시간, 로딩·에러, 오버플로, 시세 미수신 행 정렬)이 **기록되어 있는지** 확인한다. 구현은 됐는데 기록이 없으면 그것도 미완으로 잡는다.
4. `flutter analyze` 를 돌려 경고 수를 센다.

## 출력 형식

화면별로 아래 표 한 개씩. 근거는 `파일:줄` 로 붙인다.

| 필수 항목 | 상태 | 근거 |
| --- | --- | --- |
| 등락 3상태(상승/하락/보합) | 완료 | `lib/ui/common/price_text.dart:22` |
| 정렬 바텀시트 | 부분 | 칩은 있으나 `가나다순` 미구현 `..._view_model.dart:41` |
| 스켈레톤 | 미착수 | — |

마지막에:

- **남은 필수 항목** — 마감(2026-09-14 23:59) 잔여 시간 기준 우선순위 순으로 나열. 각 항목에 예상 작업량을 한 줄로.
- **판단 기록 누락** — 구현했으나 README 에 근거가 없는 것.
- **선택 항목** — 이미 된 것만 한 줄로(안 한 것은 나열하지 않는다).

## 금지

- 코드를 고치지 않는다. 리포트 전용이다.
- 파일 내용을 덤프하지 않는다. 결론과 근거 위치만 낸다.
- 체크리스트에 없는 요구사항을 추측해 만들지 않는다. 애매하면 `docs/ASSIGNMENT.md` 원문을 인용해 확인한다.
