# 과제 1 — Flutter 화면 3개

요구사항 문구는 `app/docs/ASSIGNMENT.md` **원문 그대로** 옮겼다. 해석이 갈리면 원문을 다시 본다.
평가는 **필수** 기준. 선택은 구현하지 않아도 감점 없음 — 필수를 먼저 끝낸다.

공통 해석 기준: 다크 테마 단일 · 프레임 `393 × 852` · **상승은 빨강(`priceUpText`), 하락은 파랑(`priceDownText`)** · 보합은 `priceFlatText`/`priceFlatBg` · 여백·폰트 크기·색상은 Figma 값 그대로 · 숫자 값이 아니라 **표기 형식**을 맞춘다.

---

## 1. 관심 화면 (`01 · 관심`)

**필수**

- [ ] 종목명
- [ ] `종목코드 · 시장` (예: `005930 · 코스피`)
- [ ] 현재가
- [ ] 전일 대비 등락액과 등락률 (예: `-400 (-0.22%)`)
- [ ] 등락에 따라 색상이 바뀐다. **상승 / 하락 / 보합 세 가지 상태를 모두 처리**
- [ ] 상단 새로고침 버튼을 누르면 시세를 다시 조회
- [ ] 하단 탭 바로 관심 / 검색 화면 전환. `navActive` / `navInactive` 상태 스타일이 다름
- [ ] 아직 시세를 받지 못한 행은 스켈레톤 상태로 표시 (`feedbackSkeleton`)
- [ ] 관심종목이 하나도 없을 때 빈 상태 (`01 · 관심_empty`) — 별 아이콘, `관심 종목이 없습니다`, 안내 문구까지 시안대로. 이때도 헤더와 하단 탭 바 유지
- [ ] 정렬 기능 (`01 · 관심_sort`)
  - [ ] 헤더 우측에 현재 정렬 기준을 보여주는 칩, 누르면 정렬 바텀시트가 열림
  - [ ] 정렬 기준 `현재가순`, `등락률순`, `가나다순` 세 가지, 선택된 항목에 체크 표시
  - [ ] 선택하면 목록 순서가 바로 바뀌고 헤더 칩 문구도 함께 바뀜

**선택**

- [ ] Pull to refresh
- [ ] 관심종목 삭제 (스와이프 등)
- [ ] 정렬 기준을 앱 재실행 후에도 유지

## 2. 검색 화면 (`02 · 검색`)

**필수**

- [ ] 검색 입력창과 입력 내용을 지우는 버튼
- [ ] 종목명 — **검색어와 일치하는 부분을 하이라이트** (`searchHighlight`)
- [ ] `종목코드 · 시장`
- [ ] 관심 등록 버튼(별 아이콘). `favoriteActive` / `favoriteInactive` 로 상태가 달라짐
- [ ] 별 아이콘을 누르면 관심 등록 / 해제가 즉시 반영
- [ ] 등록 토스트 — 채워진 별 아이콘 + `관심이 등록되었습니다`
- [ ] 해제 토스트 — 비어있는 별 아이콘 + `관심이 해제되었습니다`
- [ ] 토스트의 배경, 라운드, 아이콘과 문구의 간격을 Figma 기준으로
- [ ] 검색 결과 행을 누르면 종목 상세 화면으로 이동
- [ ] 검색 전 초기 상태 (`02 · 검색_empty`) — 돋보기 아이콘, `종목을 검색해 보세요`, 안내 문구까지 시안대로
- [ ] 검색 결과 없음 (`02 · 검색결과_empty`) — `'{검색어}'와 일치하는 검색 결과를 찾지 못했습니다.` 에 **사용자 입력이 그대로** 들어감
- [ ] 입력을 지우면 다시 초기 상태로 돌아감

**선택**

- [ ] 입력 디바운스 처리
- [ ] 검색어 입력 중 로딩 표시
- [ ] 최근 검색어
- [ ] 토스트 등장 / 퇴장 애니메이션

## 3. 종목상세 화면 (`03 · 종목상세`)

**필수**

- [ ] 상단에 뒤로 가기, 종목명, `종목코드 · 시장`, 관심 등록 버튼
- [ ] 현재가와 전일 대비 등락을 크게 표시. 등락 방향 아이콘(▲ / ▼) 포함
- [ ] 기간 탭 `1개월` / `3개월` / `6개월` / `1년` 이 **모두 동작**
  - [ ] 선택된 탭은 `accentDefault` / `accentBg` 스타일
  - [ ] 탭을 바꾸면 차트와 일별 시세 표의 기간이 바뀜
- [ ] 캔들 차트. 상승 / 하락 캔들은 `chartLineUp` / `chartLineDown`
- [ ] 요약 카드 — `시가`, `고가`, `저가`, `거래량`, `시가총액`. 거래량과 시가총액은 축약 (예: `29,113천`, `1,063조`)
- [ ] `일별 시세` 표 — 컬럼 `날짜`, `종가`, `등락`, `거래량`. 날짜는 `MM.DD`, 등락은 부호와 색상 함께

**선택**

- [ ] 차트 축 라벨, 거래량 바 (`chartAxisLabel`, `chartVolumeBar`)
- [ ] 차트 영역 채우기 (`chartAreaUp`, `chartAreaDown`)
- [ ] 차트 터치 시 크로스헤어 / 툴팁
- [ ] 일별 시세 표의 무한 스크롤
- [ ] 차트 전환 애니메이션

> 차트 안쪽 그림(캔들 두께·간격·축 눈금·Y축 범위)은 시안과 달라도 감점 없음. 단 위아래 요소 배치가 어긋나지 않을 정도의 높이 + 캔들 색상은 맞춘다. 패키지를 썼다면 달라진 부분과 이유를 메모에.

## 4. 상태 동기화 (전체 필수)

- [ ] 관심 상태가 바뀌면 관심 · 검색 · 상세 화면의 별 아이콘이 모두 함께 바뀜
- [ ] 검색 직후에도 현재 관심 상태가 결과에 반영됨
- [ ] 검색 화면에서 관심 등록한 종목이 관심 화면 목록에 반영됨
- [ ] 상세 화면에서 관심을 해제하고 돌아오면 목록에도 반영됨

> 관심 목록을 앱 재실행 후에도 유지하는 것(로컬 저장)은 **선택**.

## 5. 데이터 (`docs/NAVER_API.md`)

- [ ] 검색 자동완성 — 국내 주식만, 6자리 종목코드만, canonical id `domestic:{symbol}`
- [ ] 실시간 시세 — **관심종목을 한 번의 요청으로** (`SERVICE_ITEM:005930,000660`), symbol 기준 조회 가능한 형태로 정리
- [ ] 등락액 `nv - pcv`, 등락률 `(nv - pcv) / pcv`, 시가총액 `nv × countOfListedStock`
- [ ] 종목 메타데이터 — 이름·거래소명을 UI 모델에 연결
- [ ] 일별 시세 HTML — **UTF-8 아님**(인코딩 처리), 표 숫자 순서 `종가·전일비·시가·고가·저가·거래량`, 날짜는 `yyyyMMdd` 정규화
- [ ] **필요한 만큼만 받고 이미 받은 페이지는 재사용**, `lastPage` 초과 요청 금지
- [ ] 요청 · 파싱 · DTO 작성 · 모델 연결 **네 가지 모두** 구현
- [ ] **`USE_FAKE` 없이 endpoint 4개가 실제로 응답하고 화면에 값이 들어온다** (검색 · 실시간 시세 · 메타 · 일별 시세)
- [ ] mock 응답을 `app/assets/mock/` 에 저장하고 커밋 — `NAVER_API.md` 기준 **권장**(리뷰 도움). 파싱 확정 · 테스트 입력용이지 제출 동작이 아니다
