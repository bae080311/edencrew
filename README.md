**데이터** — endpoint 4개 요청 · 파싱 · DTO 4종 · 모델 연결, 일별 시세 HTML 파싱(EUC-KR · 컬럼 순서 · 전일비 부호 · `lastPage`), 실시간 시세 **batch 조회**(관심종목을 한 번에), 일별 시세 **페이지 캐시**(필요한 만큼만 받고 재사용, `lastPage` 초과 요청 없음), 포맷 단일 지점(`core/format.dart`).

## 기술 선택과 이유

전체 근거는 [`ARCHITECTURE.md`](docs/ARCHITECTURE.md) 에 있습니다.

- **상태관리 · DI — `provider` + `ChangeNotifier`.** 화면 3개 규모에서 충분하고 상태관리와 주입을 같은 도구로 해결합니다. Riverpod 은 이 규모에서 얻는 이득보다 학습 비용이 크고, 주입 지점이 `main.dart` 하나여서 `get_it` 같은 DI 컨테이너도 두지 않았습니다.
- **HTTP — `http`.** GET 4개뿐이라 dio 의 인터셉터 · `CancelToken` · 재시도가 쓰이지 않습니다. 요청 취소는 ViewModel 의 latest-wins 로 해결합니다. 오히려 응답이 EUC-KR 이라 `bodyBytes` 를 그대로 코덱에 넘기는 `http` 가 다루기 쉬웠습니다 — dio 는 기본이 자동 변환이라 `ResponseType.bytes` 로 되돌려야 합니다.
- **영속성 — `shared_preferences`.** 저장할 것이 관심 목록 · 정렬 기준 · 최근 검색어 셋뿐이고 전부 단순 key-value 라 Hive · Isar 를 들일 이유가 없습니다.
- **포맷 — `intl` 없이 `core/format.dart`.** 축약 단위(천 · 조)가 한국식 표기라 `intl` 을 쓰더라도 결국 직접 써야 합니다.
- **캔들 차트 — `CustomPainter` 로 직접.** 패키지를 쓰면 캔들 색을 토큰으로 맞추고 시안 여백 · 높이를 끼워 넣는 일이 더 커집니다. 그릴 것이 심지 선과 몸통 사각형뿐이라 직접 그리는 편이 짧고 의존성도 늘지 않습니다.
- **SVG 아이콘 — `flutter_svg`.** Material 아이콘으로 대체하면 별 · 정렬 · 새로고침의 부피와 획이 시안과 어긋납니다. 평가가 "Figma 와 최대한 가깝게"를 보므로 글리프를 맞추는 쪽을 택했고, 그 대가로 패키지 하나를 늘렸습니다. 색은 `ColorFilter` 의 `srcIn` 으로 덮어 토큰으로 전환합니다.
- **EUC-KR 디코딩 — `cp949_codec`.** `dart:convert` 의 `Encoding` 을 구현해 `utf8` 자리에 그대로 들어가고, 순수 Dart 라 유닛 테스트에서 mock 바이트를 그대로 검증할 수 있습니다(CP949 ⊃ EUC-KR). 후보 셋이 탈락했습니다 — `euc` 는 EUC-JP · Shift_JIS 전용, `charset_converter` 는 플랫폼 채널이라 유닛 테스트에서 못 돌고, `charset` 의 `eucKr` 은 **디코딩이 깨져 있습니다**(아래 "막혔던 지점").
- **디자인 토큰 — 값은 수정하지 않고 텍스트 스타일만 추가.** 스타터 토큰에 글자 크기 · 행간이 없는데, Figma Variables 에 없을 뿐 이름 붙은 텍스트 스타일(`display/price` · `title` · `body` · `label` · `caption`)로는 정의되어 있었습니다. 화면마다 크기를 적으면 같은 값이 흩어지므로 그 스타일을 `AppTypography` 상수로 1:1 옮겼습니다. 새 스케일을 지어낸 것이 아닙니다.

## 직접 판단한 부분과 이유

시안이나 과제 원문에 정의되어 있지 않아 직접 결정한 것들입니다.

### 로딩 · 에러 · 오버플로 *(과제가 직접 판단하라고 지목한 항목)*

- **관심 화면에는 로딩 전용 화면이 없고, 상세 화면 첫 조회에는 스피너 하나를 둡니다.** 관심 목록은 종목명을 이미 들고 있어 조회 중에도 행이 그려지고 가격 자리만 비므로, 과제가 요구한 "시세 미수신 스켈레톤"이 로딩 표현을 겸합니다. 상세는 종목명 · 가격 · 표 어느 것도 미리 들고 있지 않아 스켈레톤으로 채울 형태가 없습니다. 검색도 같은 이유로 이미 받아둔 결과를 지우지 않고, 결과가 하나도 없을 때만 스피너를 보입니다.
- **갱신 실패로 이미 받아둔 목록을 지우지 않습니다.** 처음 조회부터 실패해 쓸 수 있는 값이 하나도 없을 때만 에러 화면으로 바꿉니다. 상세의 기간 전환만 실패하면 화면을 유지하고 탭 아래 한 줄로 알립니다. 에러 문구는 `시세를 불러오지 못했습니다` 하나로 뭉갰습니다 — 사용자가 할 수 있는 일이 `다시 시도` 뿐이라 원인별로 나눌 이유가 없습니다(응답 형식이 어긋난 경우만 따로 가릅니다). 타임아웃은 10초입니다.
- **시세를 받지 못한 종목은 결과에서 빼고 행은 스켈레톤으로 남기며, `현재가순` · `등락률순` 에서 맨 아래로 보냅니다.** 한 종목이 거래정지 등으로 비어 올 때 목록 전체를 실패로 처리하면 나머지까지 못 보게 됩니다. 값 없는 행을 값 있는 행 사이에 끼우면 정렬이 어긋나 보이고, `가나다순` 은 이름이 있으니 그대로 줄을 세웁니다. 상세의 빈 값 자리는 `-` 입니다 — 0 으로 채우면 실제 값처럼 보입니다.
- **긴 종목명은 한 줄로 자르고 가격 영역 폭을 먼저 확보합니다.** 이름이 줄바꿈되면 행 높이가 들쭉날쭉해지고, 가격이 밀려 잘리면 목록의 쓸모가 사라집니다. 결과 없음 문구에서는 **검색어 쪽**을 20자에서 자릅니다 — 문구 전체를 말줄임하면 정작 읽어야 할 `일치하는 검색 결과를 찾지 못했습니다.` 가 통째로 잘려 나갑니다.
- **관심 등록 · 해제 토스트는 2초입니다.** 별 아이콘이 행에서 이미 바뀌므로 토스트는 보조 확인이고, 연달아 등록할 때 앞 토스트가 다음 조작을 가리면 안 됩니다. 상세 화면에서는 띄우지 않습니다 — 시안의 토스트 프레임 둘이 모두 검색 화면이고, 헤더의 별이 눈앞에서 바뀝니다.

### 시안 · 원문과 다르게 구현한 것

- **`priceUpBg` · `priceDownBg` · `priceFlatBg` 세 토큰은 쓰지 않았습니다.** 원문이 "보합(0%)은 `priceFlatText` / `priceFlatBg`를 사용합니다"라고 글자색과 배경색을 짝으로 지목해서 한 번은 등락을 배경 배지로 만들었습니다. 그런데 **시안 세 화면 어디에도 등락 배경이 없습니다** — 전부 색 글자뿐입니다. 원문이 시안보다 앞서간 것으로 보고 되돌렸고, **문서와 시안이 다르면 시안이 기준**이라는 것을 이 자리에서 정했습니다.
- **탭 바 높이에 `size/tabbar`(56) 토큰을 쓰지 않았습니다.** 시안의 `Tab bar` 프레임이 여섯 화면 모두 **63px**(상하 여백 8 + 탭 47)입니다. 토큰 값을 강제하면 오히려 시안과 어긋납니다.
- **요약 카드 셀 폭을 시안의 `115` · `176.5` 고정 대신 균등 분배로 바꿨습니다.** 고정값은 375 폭(SE)에서 한 줄에 들어가지 않습니다. 배치(3칸 + 2칸)와 간격 8은 그대로 두고 폭만 `Expanded` 로 나눴습니다.
- **차트** — 과제가 "차트 안쪽 그림은 시안과 달라도 감점하지 않는다"고 명시한 범위입니다. 캔들 색은 전일비가 아니라 **몸통 방향(종가 − 시가)** 으로 가릅니다(전일 종가 100 · 시가 110 · 종가 105 인 날은 몸통이 내렸는데 전일비로는 상승 색이 됩니다). 심지는 시안의 `0.3` 대신 최소 `0.8` 로 그립니다 — 1년치 245개를 393 폭에 그리면 사라집니다. 쓰이지 않던 `chartAxisLabel` · `chartVolumeBar` · `chartArea*` 네 토큰은 축 라벨 · 거래량 바 · 영역 채우기로 채웠습니다. 캔들 색 토큰과 차트 높이 200 은 시안 그대로입니다.
- **검색 · 관심 행의 시장명은 자동완성 응답(`typeName`)에서 가져옵니다.** `NAVER_API.md` 는 메타 endpoint 를 지목했지만, 검색 결과 10건마다 메타를 부르면 화면 하나에 요청이 열한 번 나갑니다. 자동완성이 같은 값을 이미 담고 있고, 메타 endpoint 는 상세 화면에서 호출하므로 요청 · 파싱 · DTO · 모델 연결은 그쪽에서 충족합니다.
- **`Scale` 컬렉션에 없는 시안 값(행 내부 간격 2, 아이콘 18 · 22 · 24 · 40 등)도 `AppDimens` 에 추가해서 씁니다.** 위젯 안 `const` 로 두면 같은 값이 화면마다 흩어져 "간격은 토큰으로만" 규칙이 무의미해집니다. 대응표는 Figma 변수에서 온 것과 시안 레이어에서 읽은 것을 갈라 적었습니다. 다만 **한 위젯의 상자 크기**(스켈레톤 막대, 차트 높이, 표의 날짜 칸)는 위젯에 남깁니다.

### 데이터 표기

- **EUC-KR 디코딩을 일별 시세 HTML 뿐 아니라 실시간 시세 JSON 에도 적용합니다.** `NAVER_API.md` 는 HTML 만 경고했지만, 실시간 시세도 `charset=EUC-KR` 로 내려와 종목명(`nm`)이 깨집니다.
- **등락액 · 등락률을 응답의 `cv` · `cr` 대신 `nv - pcv` 로 직접 계산합니다.** `cv` · `cr` 에는 부호가 없고 방향이 별도 코드(`rf`)에만 담겨 옵니다.
- **축약(`29,113천` · `1,063조`)은 버림, 등락률은 소수 2자리, 보합은 부호 없이 `0 (0.00%)`.** 시안이 표기 형식만 보여주고 절삭 방식을 정하지 않았는데 반올림하면 실제보다 큰 값으로 보이고, 0 에 `+` 가 붙으면 상승으로 읽힙니다.

### 저장과 오류 노출

- **저장은 `state/preferences.dart` 한 곳에서만 합니다.** `shared_preferences` 라는 이름이 화면과 스토어에 퍼지면 저장 방식을 바꿀 때 모든 파일을 열어야 합니다. `FavoritesStore` · 두 ViewModel 에는 **선택 인자**로 넘겨 테스트는 저장 없이 돕니다. 저장값이 깨져 있으면 빈 값으로 시작하고(회귀 테스트로 고정), 저장소 초기화가 실패해도 앱은 뜹니다.
- **삼킨 예외는 스택까지 남기고, 아무도 받지 않는 예외는 `main` 이 받습니다.** 화면이 원인을 문구 하나로 뭉개므로 개발 중에 원인이 보이지 않습니다. `FlutterError.onError` 와 `PlatformDispatcher.instance.onError` 로 위젯 빌드 오류와 `await` 없이 던진 Future 까지 같은 형식으로 남깁니다. 전부 `assert` 안이라 release 빌드에서는 빠집니다.

### 과제 2 — Lucy Studio

- **캔버스를 iPhone 12 Pro(390 × 844)로 두었습니다.** 시안 기준 프레임 393 × 852 가 Lucy 의 해상도 목록에 없습니다. 그 값은 Figma 에서 읽어낸 **기준 프레임이지 캔버스 크기가 아니므로**, 고정으로 맞출 여백 · 폰트 · 아이콘 크기는 시안 값을 그대로 넣고 화면을 채우는 폭만 캔버스에 맡겼습니다.
- **색을 Lucy 토큰이 아니라 ARGB 로 직접 넣었습니다.** 새 Lucy 프로젝트에 색 토큰이 하나도 없어 `setTextColor` 가 받을 이름이 없었습니다. 토큰 체계를 새로 세우는 대신 과제 1 의 `app/lib/theme/` 값을 그대로 옮겨(`#FFFF5B5B` · `#FF4D9BEE`) **두 과제의 색이 같은 출처에서 나온다는 점**을 유지했습니다. 토큰 정의는 선택 항목이라 미뤘습니다.
- **다이얼로그는 별도 페이지이고, 닫기는 열린 폼 자신이 부르는 `$form.close(result)` 입니다.** `closeDialog` 는 다이얼로그를 **연 쪽**에서 부르는 함수라 열린 폼 안에서는 동작하지 않습니다. 결과 객체를 콜백으로 돌려주므로 등록 값 전달과 `x` 취소(= `null`)를 한 경로로 처리했습니다.
- **목표가에 단위를 붙이지 않고(시안이 `200,000` 으로만 씁니다), 숫자 필터는 등록 시점에 겁니다.** 입력 중에 막으면 붙여넣기가 불편합니다. 빈 값이면 닫지 않고 그대로 두며, 시안에 에러 상태가 없어 문구는 띄우지 않습니다.

## 막혔던 지점과 어떻게 접근했는지

- **macOS 앱에서만 조회가 전부 실패했습니다.** 점검 도구(`tool/check_endpoints.dart`)로는 endpoint 4개가 모두 응답하는데 앱에서는 아무것도 오지 않았습니다. 원인은 망이 아니라 **App Sandbox** 였습니다 — Flutter 의 macOS 템플릿은 들어오는 연결(`network.server`)만 넣어주고 **나가는 연결(`network.client`)은 켜주지 않습니다.** 점검 도구는 샌드박스 밖의 Dart VM 에서 돌아 이 차이를 드러내지 못했습니다. entitlements 에 권한을 넣고 빌드된 `.app` 에 실제로 박혔는지 `codesign -d --entitlements` 로 확인했습니다.
- **패키지가 제공하는 EUC-KR 디코더가 깨져 있었습니다.** `charset` 의 `eucKr` 로 `삼성전자` 가 `鋱鏋飜飅` 로 나왔습니다. 내부 매핑 테이블 두 개의 이름이 서로 반대로 붙어 디코더가 역방향 테이블을 참조하고 있었습니다. 고른 직후 실제 바이트로 돌려보지 않았다면 화면까지 가서야 알았을 문제라, 이후로는 파서에 물리기 전에 mock 바이트로 먼저 검증했습니다.
- **1년 기간이 눈에 띄게 느렸습니다.** 짐작하지 않고 `tool/measure_period.dart` 로 구간을 나눠 쟀습니다. 25페이지 병렬 요청 0.24초 · 파싱 장당 1.7ms — 네트워크도 파싱도 아니고 **위젯 천 개 이상을 한 프레임에 세우는 쪽**이 병목이었습니다. 본문을 `CustomScrollView` 로 바꾸고 표를 sliver 로 빼서 해결했고, 선택 항목이던 무한 스크롤도 이것으로 해결됩니다.
- **과제 2 의 "행을 컴포넌트로 분리해 재사용"은 끝까지 구현했다가 되돌렸습니다.** `AlertRow` 에 행 레이아웃을 옮기고 노출 변수 셋과 속성 바인딩 셋(`txtName.text` · `txtPrice.text` · `txtPrice.style.color`)을 건 뒤 `ListView` 자식을 그 인스턴스로 교체했습니다. 세 가지를 확인했습니다 — ①컴포넌트 안의 위젯 id 는 밖에서 보이지 않고(`txtName is not defined`), ②인스턴스는 `setVar` · `getVar` 를 갖고도 선언한 변수를 모르며(`getVar` → `undefined`), ③마스터에 고정 문자열과 변수 기본값을 박고 실행하니 **행 자리에 아무것도 그려지지 않았습니다.** 스튜디오 캔버스에는 보이는데 프리뷰 런타임이 인스턴스를 렌더하지 않았습니다(Lucy Studio 0.0.34). 값 주입 이전에 렌더가 안 되는 문제라 인라인 행으로 되돌렸고, `assets/component/AlertRow.lfc` 는 변수 · 바인딩까지 완성된 상태로 남겨 두었습니다.


## AI 활용 범위

Claude Code 를 구현 · 리뷰 · 문서 작성에 활용했습니다. **무엇을 만들지와 어떻게 판단할지는 직접 정했고, 도구는 그 결정을 코드로 옮기는 데 썼습니다.**

판단의 근거는 두 문서에 남아 있습니다 — 위 "직접 판단한 부분과 이유", 그리고 [`ARCHITECTURE.md`](docs/ARCHITECTURE.md) 의 아키텍처 결정과 **바꾼 이유까지 포함한 변경 이력**입니다. 결정할 때마다 그 자리에서 적었고, 뒤집은 것은 뒤집은 이유를 함께 남겼습니다.

판단이 갈렸던 자리를 예로 들면, 문서와 시안이 어긋났을 때 시안을 기준으로 삼았고(등락 배경), 과제 2 의 행 컴포넌트화는 구현까지 간 뒤 런타임이 인스턴스를 렌더하지 않는 것을 확인하고 되돌렸으며, 의존성은 필요를 확인한 뒤에만 늘렸습니다(무엇을 검토하고 탈락시켰는지까지 기록). 생성된 코드는 전부 읽고 반영했습니다.
